Pollinations for Figma

Generate and edit images on the canvas with Pollinations — paying with your own Pollen.

What it does

  • Generate — type a prompt, the image lands on a new layer or frame.
  • Edit — send the selection to an image-input model; the result lands on a new layer.
  • Models come from the live catalog (https://gen.pollinations.ai/image/models).
  • Sign in with the device flow — no API key is pasted into Figma.

Install

  1. Download this repository.
  2. In Figma: Plugins → Development → Import plugin from manifest…
  3. Pick dist/manifest.json.
  4. Run the plugin, connect your Pollinations account, generate.
